Line graphs are very commonly used plots, especially in showing the change of numerical values
over time. Small design choices, such as using one color or many colors and placing labels inside the
graph or in a legend, may change how accurately people read values from a graph. Many design
guidelines are based on experience or intuition, but there is still room to test how these choices
affect accuracy in a controlled setting.

In our project, we studied a 2 ×2 factorial experiment. The first factor was Color: a single-color
line with different lightness levels versus a line graph where each line has its own color. The second
factor was Label type: a separate legend versus inline labels placed near the lines. We combined
these two factors to form four conditions: single + legend, single + inline, color + legend, and color + inline. Through experiments, we evaluated these factors’ impact on the accuracy of reading data from a line graph.

Intuitionally, we believed that using different colors and inline labels both improve accuracy
because these designs make the differences between lines in the image more obvious, reducing
identification errors and increasing accuracy. Some rigorous statistical methods will be used to
verify/refute these intuitions.
